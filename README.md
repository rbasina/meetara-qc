# meeTARA QC: Quantum Evaluation Zero to Hero

meeTARA QC is a structured tutorial repository that teaches quantum computing through an evaluation and benchmarking mindset.

The course starts from fundamentals and progresses to expert benchmarking practice with reproducibility and cost-awareness.

## Course Scope
1. Foundation pre-chapter (Chapter 00)
2. 12 core chapters (Chapter 01 to Chapter 12)
3. 12 mapped practical notebooks (Notebook 01 to Notebook 12)

Chapters are the primary learning path: read the chapter first for concepts and definitions, then open the matching notebook for practice.

## What Learners Build
1. Circuit-level intuition and correctness checks
2. Noise-aware quality evaluation workflows
3. Simulator vs hardware comparison discipline
4. Reproducible benchmark reporting and capstone artifacts

## Repository Layout
1. chapters: lessons, frameworks, and reference guides
2. notebooks: beginner, intermediate, and advanced practical labs
3. quizzes: chapter-level understanding checks
4. projects: mini-projects and capstone tasks
5. rubrics: evaluation criteria for submissions

## Learning Principles
1. Plain-English first, then technical depth
2. Every claim should be supported by metrics
3. Repeated runs over single-run conclusions
4. Quality plus cost reporting, not quality alone

## Reference Style
1. Chapters stay as the main learning path.
2. Each chapter can include clickable https references for definitions and source material.
3. Use the official docs links in the chapter footer when you want the primary source.

## Cost-Conscious Policy
1. Simulator-first for beginner and most intermediate work
2. Hardware usage only when chapter objectives require it
3. Controlled shot budgets and repeat policies
